## Módulo 3 · Ventas_Tech_DB

- **Motor:** SQL Server (SSMS)
- **Modelo:** `categorias (1) ── (N) productos (1) ── (N) ventas (N) ── (1) clientes`
- **Secciones del script:** DROP · CREATE · INSERT · VALIDACIÓN
- **Resultado de la validación:** 4 categorías, 5 clientes, 6 productos, 10 ventas (25 registros)
- El script es repetible: se puede ejecutar dos veces seguidas sin errores.
